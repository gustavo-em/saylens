# SpellForMe

SpellForMe is an Android-first React Native side project that turns the camera
into an interactive English-learning experience.

The repository is currently in its architecture and planning phase. Product
code and runtime dependencies will be introduced only after the technical
boundaries and initial decisions are documented.

## Initial product idea

1. Detect common objects in the live camera preview.
2. Render a stable, clickable label over each detected object.
3. Open an educational detail view with the English word, pronunciation,
   meaning, and an example sentence.

## Status

- Platform: Android first
- UI: React Native
- Camera: VisionCamera 5
- Object detection: on-device model through a Kotlin adapter
- Repository stage: foundation

Architecture, roadmap, setup instructions, and contribution guidelines will be
added in the next repository milestones.
