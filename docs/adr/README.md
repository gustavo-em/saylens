## Lifecycle

An ADR is `Proposed`, `Accepted`, `Superseded`, or `Rejected`. Accepted ADRs
are not rewritten to hide a former decision. A new ADR supersedes them and
links back to the historical record.

Use [the template](template.md) for future decisions.
